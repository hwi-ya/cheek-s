# 고유값 (eigenvalue)
  | 정의                      | 행렬 $A$에 대해, $Ax = λx$를 만족하는 스칼라 값 λ를 고유값이라 한다.                                                                 |
  |--------------------------|---------------------------------------------------------------------------------------------------------------------------------------|
  | 대칭 행렬의 특징          | - 대칭 행렬의 고유값은 항상 실수 이다.<br> - 복소수 고유값이 존재하지 않는다.                                                             |
  | 고유값을 이용한 대각화    | - 고유값을 이용하면 행렬을 대각행렬로 변환 가능하다.<br> - $A$가 대각화 가능하면, $A = PDP^{-1}$ 형태로 표현된다.                          |
  | 행렬의 성질과 고유값 관계 | - 행렬 $A$의 행렬식과 고유값은 관계가 있다( $det( A - λI ) = 0 $)<br> - 대칭 행렬 $A$가 양의 정부호 이려면, 모든 고유값이 양수이어야 한다.  |
  <br/>

# 고유 벡터 (eigenvector)
  | 정의                      |행렬 $A$와 고유값 $λ$에 대해, $Ax = λx$를 만족하는 벡터 $x$를 고유벡터라 한다.                                                          |
  |--------------------------|---------------------------------------------------------------------------------------------------------------------------------------|
  | 대칭 행렬의 특징          | - 대칭 행렬의 서로 다른 고유값에 대응하는 고유벡터는 항상 직교 한다.<br> - 즉, $λ_1 \neq λ_2$라면, $ v_1 \cdot v_2 = 0$ 이다.              |
  | 직교 행렬과의 관계    | - 대칭 행렬의 고유벡터들로 이루어진 행렬은 직교행렬이 될 수 있다.<br> - 직교 행렬 $Q$는 $Q^TQ=I$를 만족한다                                |
  | 고유벡터의 정규화 | - 고유벡터를 단위 벡터로 변환(정규화)하면 정규직교기저 가 된다.                                                               |
  <br/>
<hr>
  
# 고유 분해 (eigendecomposition)
  | 정의                      | 행렬 $A$를 고유값과 고유벡터를 이용해 분해하는 것. <br> 대칭 행렬은 항상 고유분해가 가능.                                              |
  |--------------------------|---------------------------------------------------------------------------------------------------------------------------------------|
  | 고유분해의 수식           | $A = QΛQ^T $<br> - Q : 고유벡터들로 이루어진 직교 행렬<br> - A : 고유값을 대각원소로 갖는 대각행렬                                        |
  | 고유분해의 특징           | - 대칭 행렬은 반드시 고유분해 가능 (즉, 항상 대각화 가능)<br> - $Q^T = Q^-1$을 만족하는 직교 행렬을 사용하면 계산이 단순해짐.               |
  <br/>
